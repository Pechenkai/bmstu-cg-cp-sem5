\ssr{ВВЕДЕНИЕ}

Цель работы --- создание программного обеспечения для визуализации процесса водной эрозии рельефа с возможностью изменения
физических и визуальных параметров.

Для достижения поставленной цели требуется решить следующие задачи:
\begin{itemize}
    \item проанализировать алгоритмы компьютерной графики для построения изображения;
    \item выбрать подходящие алгоритмы для построения изображения рельефа и визуализации водной эрозии;
    \item спроектировать программное обеспечение;
    \item выбрать средства реализации;
    \item реализовать ПО для построения изображения рельефа и визуализации водной эрозии;
    \item исследовать зависимости времени построения изображения от размера карты высот.
\end{itemize}
