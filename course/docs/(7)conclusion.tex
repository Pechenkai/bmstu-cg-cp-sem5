\ssr{ЗАКЛЮЧЕНИЕ}

Цель данной работы была достигнута: создано программное обеспечение для визуализации процесса водной эрозии
рельефа с возможностью изменения физических и визуальных параметров модели. Все поставленные задачи были успешно решены:

\begin{itemize}
    \item проведен анализ алгоритмов компьютерной графики для построения изображения;
    \item выбраны подходящие алгоритмы для построения изображения рельефа и визуализации водной эрозии;
    \item спроектирована архитектура программного обеспечения;
    \item определены и обоснованы средства реализации программного обеспечения;
    \item выполнено исследование зависимости времени построения изображения от размера карты высот, показавшее линейный характер зависимости;
\end{itemize}
