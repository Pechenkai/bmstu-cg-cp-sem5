# Курсовая работа по компьютерной графике

**Тема:** визуализация процесса водной эрозии рельефа.

Рендеринг выполняется собственным растеризатором: без OpenGL и других графических API.

## Возможности

- Генерация карты высот заданного размера на основе многослойного шума Перлина.
- Имитация водной эрозии движением капель к наименьшему соседнему значению высоты, размывом и осаждением перенесённого материала.
- Пошаговое отображение процесса эрозии.
- Построение треугольной сетки по карте высот и расчёт нормалей.
- Программная растеризация с буфером глубины, освещением Ламберта и интерполяцией Гуро.
- Цветовая шкала рельефа по высоте, настройка цвета и интенсивности источника света.
- Управление положением камеры кнопками интерфейса и клавишами `W`, `A`, `S`, `D` в области рендера.
- Восстановление исходной карты высот после эрозии.

## Стек

- C++;
- Qt Widgets и `QImage` для интерфейса и кадрового буфера;
- GLM для векторной и матричной математики;
- OpenMP для распараллеливания обработки граней при рендеринге.
